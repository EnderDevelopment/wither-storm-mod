# Wither Storm Mod

A terrifying Wither Storm boss with advanced AI and destructive behaviors for Minecraft 1.20.5 on Fabric. This mod introduces a fully functional Wither Storm boss that features advanced AI, realistic animations, and a variety of destructive abilities. The Wither Storm can grab players, slap them with its tentacles, slam the ground, crush players, and even eat them. It also has the ability to destroy Nether portals, terrain, and consume nearby entities.

## Install

1. Download the mod jar file from the [GitHub releases page](https://github.com/EnderDevelopment/wither_storm/releases).
2. Place the jar file in the `mods` folder of your Minecraft installation.
3. Launch Minecraft with the Fabric loader installed.

## Use

1. Summon the Wither Storm using the command `/summon wither_storm`.
2. The Wither Storm will target nearby players and use its abilities to attack them.
3. Monitor the Wither Storm's health and abilities using its unique GUI.
